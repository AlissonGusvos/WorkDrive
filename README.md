# WorkDrive

Sistema web para ajudar oficinas mecânicas a organizar clientes, veículos, ordens de serviço e peças em estoque.

## Funcionalidades

- **Painel geral:** exibe ordens em aberto, total de clientes, faturamento em execução e peças com estoque baixo. Também mostra ordens recentes e itens que precisam de reposição.
- **Clientes e veículos:** permite cadastrar clientes com telefone e dados do veículo, além de remover cadastros.
- **Ordens de serviço:** permite criar ordens associadas a um veículo, acompanhar o serviço por etapa — *Aguardando Peça*, *Em Execução* e *Concluído* —, alterar a etapa e excluir ordens.
- **Estoque:** permite cadastrar peças com quantidade, estoque mínimo e preço; atualizar quantidades e excluir itens. O sistema sinaliza quando uma peça precisa ser reposta.

## Tecnologias

- HTML
- CSS
- JavaScript
- `localStorage` do navegador para salvar os dados

## Como executar

1. Baixe ou clone os arquivos do projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Cadastre clientes e veículos antes de criar ordens de serviço.

> Os dados ficam salvos no armazenamento local do navegador. Eles não são compartilhados entre navegadores ou dispositivos.
